# NotchAgenda 使用指南

## 1. 安裝與開啟

需求：macOS 14 或以上、支援 Swift 6 的完整 Xcode。本專案目前提供本機建置方式。

1. 結束舊版 FlowTasks 或 NotchAgenda。
2. 在專案目錄執行 `./scripts/run-mac.sh`。
3. 腳本會編譯並建立 `.build/NotchAgenda.app`，然後開啟 App。
4. 啟動後主視窗會收起；有瀏海時，瀏海下方會有細提示；無瀏海時，頂部中央保留黑色膠囊。選單列亦有清單圖示。

也可直接打開已建置的 `NotchAgenda.app`。更新原始碼後，需先結束舊程序再重新執行腳本，單純再次開啟 `.app` 不會替換正在執行的程式。

目前不會自動設定登入時啟動。如需要，可自行將建置完成的 App 加入 macOS 登入項目；持續更新時保留同一個 App 位置。

## 2. 從瀏海或頂部叫出面板

### Hover

- 有瀏海：入口按系統回報的相機區寬度與位置貼齊，只在底部多留 **5pt** 細邊；把滑鼠移到瀏海或細提示，停留約 **0.24 秒**。
- 沒有瀏海：移到螢幕頂部中央的黑色入口，使用方式相同。
- 每個已連接螢幕都有入口；面板會在觸發的螢幕展開。
- Hover 只顯示面板，不會主動搶走其他 App 的鍵盤焦點。點入文字框後才開始輸入。
- 無瀏海的膠囊保留品牌與今日日事項數量，包含過期延續項目；有瀏海時收起只顯示一條細提示，避免額外加寬或加高相機區。
- 系統未提供相機區矩形時，會使用安全區高度推算有界的備用尺寸；沒有瀏海的螢幕維持原尺寸與位置。

入口不攔截選單列的點擊。快速掠過中央不會立即打開面板；拖曳滑鼠按鍵時也不會觸發展開。

### 收起與釘選

- 停留後，面板以約 **0.52 秒**慢慢向下展開，配合淡入。
- 滑鼠離開入口及面板約 **0.7 秒**後，面板以約 **0.46 秒**向上收回並淡出。
- 自動收起途中返回仍可見的面板，會從當前位置接續展開，不會先消失再跳出。
- macOS 開啟 Reduce Motion 時，略過位移與淡入淡出。
- 在入口與面板間移動時，有額外的容許區域，避免經過小間隙就關閉。
- 點面板頂部的圖釘，保持展開；取消釘選後恢復自動收起。
- 點向上箭頭或按 **Esc** 可收起。關閉後需離開入口再移回，避免立即重開。
- 正在文字框輸入、開啟日期／事項選單、操作對話框或按住滑鼠時，面板會保持展開。
- 編輯結束後，點回其他 App 並移開滑鼠，即可恢復自動收起；亦可使用 Esc。

### 手動開啟

選單列清單圖示提供：

| 選項 | 功能 |
| --- | --- |
| 顯示／隱藏頂部待辦 | 手動叫出或收起面板；手動叫出預設釘選 |
| 開啟主視窗 | 開啟較大的獨立視窗 |
| 啟用頂部 Hover | 開關 hover 入口；關閉後亦停止 hover 輪詢 |
| 保持面板展開 | 展開時可切換釘選 |
| 結束 | 保存日記草稿後結束 App |

點 Dock 的 NotchAgenda 圖示也可叫出主視窗。關閉主視窗不會結束 App，hover 入口仍可使用。要真正停止入口與背景程式，請選「結束」。

## 3. 設定、語言與筆記本外觀

點內頁右上角的齒輪，或從選單列選「設定…」。主視窗亦可使用 **⌘ ,** 開啟設定。

### 介面語言

可選繁體中文、简体中文及 English。切換後立即更新 App 按鈕、提示、選單、月曆星期及日期顯示；不需要重啟，也不會翻譯或清空你寫的事項與日記。系統錯誤的詳細描述保留系統原文。

### 選擇外表與內頁

App 保留原本五個橫向分頁，打開即可查看事項和輸入，不經過封面書櫃。

「筆記本外表」可選原版米白、溫柔粉色、沉穩大叔（棕色皮革與縫線感）、極簡線條。預設原版米白，保留原本日記介面的佈局。

「內頁紙張」可獨立選橫線、方格、點陣或空白，適用於事項及日記區域。例如粉色外表配點陣紙、沉穩外表配橫線紙。

語言、外表與內頁即時套用並自動保存，主視窗與浮動面板共用；切換外觀會保留未送出的待辦草稿、日記及當前分頁。舊版書櫃偏好升級後回到原版米白及全部五個分頁，已選語言保留。

## 4. 五個功能頁

| 頁面 | 用途 |
| --- | --- |
| 每日 | 安排某天要做的事；今天亦會帶上過期未完成事項 |
| 週目標 | 整週想完成的事；週一至週日為一週 |
| 月目標 | 整個曆月想完成的目標 |
| 待完成 | 尚未決定日期的想法、工作或長期目標 |
| 日曆 | 月曆、未來日期安排及過往內容 |

各頁有「待辦事項」與「已完成」。每日、週目標、月目標及日曆另有「寫日記」。

日期左右箭頭會按頁面切換：每日切一天、週目標切一週、月目標及日曆切一個月。日曆按鈕可直接選日期；「今天」可回到當下。

## 5. 新增待辦與未來安排

1. 在「待辦事項」底部輸入文字，**每行一件**，可一次貼上整份清單。
2. 選「日事項／週目標／月目標／待完成」。
3. 設定日期；週、月目標會歸入所選日期所屬的週或月。
4. 選重複方式。
5. 按「記下來」或 **⌘ Enter**。單按 Enter 是換行。

例如：在日曆選擇下星期二，再輸入「交報告」，就會安排在那一天，未到期前不會混進今天的待辦。

日曆上的小圓點表示該日有日事項，包含重複日事項。週、月目標請到各自頁面查看。

「待完成」中的項目可隨後按 `…` →「安排日期／改成目標／設定重複」，轉成某天的事項、週目標或月目標。非重複事項亦可由此改期。

## 6. 完成、移回待辦與刪除

### 完成

剔選方框或從 `…` 選「標記完成」。事項會立即離開待辦，移入同一頁的「已完成」列表，以鉛筆劃線並顯示完成時間。

需要再做時，在「已完成」找回項目，按「移回待辦」。此操作只改狀態，不新增重新開始的日誌。同一事項或同一重複期別最多保留一筆完成紀錄，再次完成會更新原筆時間。

完成列表跟隨目前頁面及日期。要找過去某天完成的事項，可先用日期選擇器或日曆切到當天；週、月目標則切到相應週期。

### 刪除與還原

- 每列垃圾桶按鈕或 `…` →「刪除事項」會移到垃圾桶。
- 刪除後不再顯示於待辦、已完成清單、數量及日曆。
- 重複事項刪除的是整個系列，包含後續期別。
- 面板內頁標題旁的垃圾桶可查看已刪除事項，按「還原」找回。
- 還原保留原本完成狀態；若還原的是已完成項目，請到「已完成」列表查看。
- 垃圾桶重啟後仍保留，完成資料不因刪除而抹除；目前沒有永久清除按鈕。

底部復原箭頭可撤回最後一次事項操作；僅單步，結束 App 後不保留。

### 拖動

右側三橫線是事項拖動把手：右拖完成，左拖移到隊尾。方框及文字區不包在拖動手勢中。

面板內頁頂部短橫線可拖動整個視窗。要長期移到別處，建議先釘選；再次從頂部叫出時會重新放回該螢幕的頂部。

## 7. 重複事項

| 設定 | 行為 |
| --- | --- |
| 日事項＋每天 | 從開始日期起，每天獨立完成，例如 Duolingo |
| 日事項＋每週 | 每週在開始日期的同一星期幾出現 |
| 日事項＋每月 | 每月相同日號，該月不足則使用月底；之後仍依原起始日計算 |
| 週目標＋每週 | 每週一開始新一期 |
| 月目標＋每月 | 每個曆月開始新一期 |

完成今天不會完成明天，把某一期移回待辦也不影響其他期。重複事項不會預先產生無限筆資料，也不會把每天漏做的項目全部塞進今天；可翻到原日期查看。

`…` →「本期後停止重複，保留紀錄」可停止後續期別。已建立的系列不直接改起始日；需要新規則時，可停止舊系列後新增。

週、月非重複目標若過期仍未完成，在今天所在頁面會延續顯示，原所屬日期保留。

## 8. 寫日記

在每日／週目標／月目標／日曆選「寫日記」，記錄發生的事、心情或回顧。

- 每天、每週、每月分開保存；同一週內的日期共用該週手記，同一月內的日期共用該月手記。
- 日曆中的文字日記對應所選日期的每日手記。
- 停止輸入約 **0.65 秒**後自動儲存，亦可按「儲存日記」或 **⌘ S**。
- 切換日期／週期或離開編輯區時，會先保存原頁。
- 顯示字數與最後儲存時間。「復原上次儲存」撤回當期最後一次保存，與事項復原分開。
- 主視窗與浮動面板使用同一份日記及草稿。

儲存失敗時，文字仍留在編輯區；面板會保持展開。結束 App 前會再嘗試保存，失敗則取消結束並顯示原因。請先處理磁碟、資料夾權限或檔案問題。

尚未加入清單的待辦輸入只保留在本次程序；真正的文字日記則會寫入檔案。

## 9. 數據儲存位置

正式 Mac 版沿用舊版資料夾，**改名不會移走資料**：

```text
~/Library/Application Support/FlowTasks/
├── tasks.json       # 事項、安排、重複規則、完成紀錄、垃圾桶
├── journal.json     # 自行撰寫的每日／週／月日記
└── preferences.json # 語言、外表與內頁紙張偏好
```

可在 Finder 按 **⌘⇧G**，貼上 `~/Library/Application Support/FlowTasks/`。檔案會在首次成功儲存相應內容後建立。

名稱仍是 FlowTasks，屬於保留資料相容的設計。它不是另一套新的 App 資料。

三個檔案都使用原子寫入，內容是本機 JSON，沒有額外加密層。垃圾桶仍存於 `tasks.json`。目前沒有 iCloud、帳戶同步或遠端資料庫。

其他位置：

| 位置 | 用途 |
| --- | --- |
| `.build/NotchAgenda.app` | 正式本機建置產物 |
| `.build/NotchAgenda-QA.app` | 獨立 QA App |
| `.build/qa/tasks.json`、`.build/qa/journal.json`、`.build/qa/preferences.json` | QA 資料，不是正式資料 |
| macOS UserDefaults，bundle `com.colday.notchagenda.mac` | hover 開關設定 |
| 記憶體 | 未送出的待辦文字、尚未保存的草稿、單步復原及釘選狀態 |

### 備份與還原

1. 從選單列結束 NotchAgenda，並確保舊版 FlowTasks 已結束。
2. 把整個 `~/Library/Application Support/FlowTasks/` 複製到備份位置。
3. 還原前同樣先結束 App，再把備份的 `tasks.json`、`journal.json`、`preferences.json` 複製回原位置。
4. 開啟 App，確認待辦、已完成、垃圾桶及日記。

備份正式資料時不要誤用 `.build/qa/`。也不要把私人 JSON 加入 Git；本 repo 只包含原始碼、測試及文件。

舊版多筆重新開始日誌會在讀取時整理，合併同一期完成紀錄並保留當前狀態；下一次正常儲存寫入新格式。讀取失敗時會停止寫入，保留原檔。

## 10. 疑難排解

| 情況 | 檢查方式 |
| --- | --- |
| 找不到主視窗 | App 預設收在頂部；用選單列「開啟主視窗」或點 Dock 圖示 |
| Hover 沒反應 | 確認程式仍在執行、已開啟「啟用頂部 Hover」，並在頂部**中央**停留，不是任意角落 |
| 面板不自動收起 | 檢查圖釘、文字輸入焦點、開啟中的選單或對話框；可直接 Esc 或向上箭頭收起 |
| 收起後立即移回卻沒開 | 先移出入口，再移入並停留；這是防止關閉後立即重開的設計 |
| 更新後還是舊介面 | 結束舊程序，再執行建置腳本；確認啟動的是 NotchAgenda.app |
| 原有待辦不見 | 查看設定內選中的筆記本、「待完成」「已完成」及垃圾桶，並檢查正式資料夾；QA 使用另一份資料 |
| 今天沒看到未來事項 | 先在日曆切到安排日期；未來事項不會提前混入今天 |
| 無法儲存 | 保留編輯區文字，檢查檔案提示、磁碟空間與資料夾權限；不要先清空原檔 |
| `swift test` 找不到 XCTest | 使用完整 Xcode：命令前加 `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` |

全螢幕、Mission Control、自動隱藏選單列及不同外接螢幕的實際視窗堆疊，仍需依使用環境檢查；遇到系統視窗遮擋時可先用選單列或主視窗操作。

## 11. 目前範圍

支援 macOS 14+ 與 iOS/iPadOS 17+。iOS 透過 TestFlight／App Store 安裝的流程見 [iOS 發佈指南](IOS_RELEASE.md)；目前開發產物未簽署，不能直接安裝到一般 iPhone。未提供通知、Apple Calendar 整合、iCloud 同步、日記全文搜尋或永久清空垃圾桶。Mac 亦尚未包含發佈簽署與公證。


## iPhone / iPad 使用

開啟 App 後，上方五個分頁對應每日、週目標、月目標、待完成與日曆。選擇日期後輸入事項，每行一件；可先選每天／每週／每月重複。未來事項到所安排的期別才出現；今天亦顯示過期未完成事項。

點方框或向右滑完成，事項移到「已完成」。完成清單內可移回待辦，不額外產生重新開始紀錄。向左滑未完成事項會移到隊尾。「…」選單可改安排或刪除；右上垃圾桶可還原。

在每日／週／月／日曆分頁選「寫日記」，依所選日期保存日、週或月手記，停止輸入約 0.65 秒自動保存，亦可手動儲存。切頁或 App 進入背景時會再嘗試保存。

右上齒輪開啟設定。介面語言使用深色區塊與白字，外表、紙張可獨立配搭。設定及文字保存在 App 與 Widget 共用的本機 App Group，包含 tasks.json、journal.json、preferences.json；不會與 Mac 自動同步。

將 NotchAgenda 加到主畫面 Widget，可查看當期未完成事項與目標。Widget 由系統安排更新，點擊後開啟 App 完成事項；不是可直接滑動完成的 Widget。每日重複事項完成後會隱藏，下一期重新出現；已刪除及未來事項不提前顯示。
