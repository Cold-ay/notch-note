# FlowTasks

Mac 浮動待辦日記。暖色紙張、橫線與鉛筆劃線；支援按日安排、週／月目標、無期限待辦、每日／每週／每月重複及完成紀錄。

## Mac 啟動

先從選單列結束舊版，再於專案目錄執行：

```sh
./scripts/run-mac.sh
```

腳本使用本機 Xcode 編譯，建立 `.build/FlowTasks.app` 並開啟。只編譯打包：`./scripts/run-mac.sh --build-only`。也可在 Xcode 開啟 `Package.swift`。

浮動面板放在相機安全區下方。拖動頂部短橫線可移位；右上角關閉鍵只隱藏面板，選單列圖示或主視窗「頂部待辦」可重新開啟。未送出的文字在隱藏時保留，結束 App 後不保留。

## 五個頁面

| 頁面 | 用途 |
| --- | --- |
| 日記 | 所選日期的日事項；今天亦顯示過期未完成的日事項 |
| 週目標 | 所選週的目標；週一至週日為一週 |
| 月目標 | 所選曆月的目標 |
| 待完成 | 沒有期限的待辦／目標，不會自動混入某一天 |
| 日曆 | 完整月曆，選擇過去或未來日期，查看並安排該日事項 |

週／月目標在今天所在頁會帶上先前仍未完成的目標，原所屬日期仍顯示。翻閱其他期間時顯示該期間的項目。未完成的重複事項不會無限累積到今天；可翻到當時的日期查看。

日曆中的小圓點表示該日有日事項，包含重複事項。週／月目標由各自頁面管理。

## 寫下與安排

1. 在底部輸入框寫待辦，每行一件，支援多行貼上。
2. 選「日事項／週目標／月目標／待完成」。週、月目標會歸入所選日期所屬的週或月。
3. 選安排日期；在日曆選取未來日期後，輸入區會跟隨該日期。
4. 選重複方式，按「記下來」或 **⌘ Enter**；Enter 保留為換行。

未來日事項不會提前出現在今天的未完成清單，到了當天就會出現。可事先翻到該日查看，亦可提前完成；安排日期及實際完成時間各自保留。

「待完成」列右側的 `…` →「安排日期／改成目標／設定重複」，可將想法移到某日、週或月。非重複事項亦可由此改期。

## 重複事項

- **日事項 + 每天**：例如 Duolingo，從開始日期起每日一個完成狀態。
- **日事項 + 每週**：每週在開始日期的同一星期幾出現。
- **日事項 + 每月**：每月在開始日期的同一天出現；該月無此日期則落在月底，下個月仍依原起始日計算。例如 1 月 31 日 → 2 月底 → 3 月 31 日。
- **週目標 + 每週**：每個週一開始新一週，完成狀態獨立。
- **月目標 + 每月**：每個曆月有獨立完成狀態。

完成今天不會完成明天；重新開啟某一期亦不影響其他期。`…` →「本期後停止重複，保留紀錄」，可以停止後續產生的期別。已建立的重複系列不直接改起始日；需要新規則時，停止舊系列並新增一件。

## 勾選、拖動與紀錄

- 勾選方框完成，事項留在原位，以鉛筆筆跡劃掉並顯示完成時間；再按一次可重新開啟。
- 方框改用原生 AppKit checkbox，32pt 點擊範圍，支援非作用中面板首擊。
- 拖動手勢只在右側三橫線把手：右拖完成，左拖移到隊尾。方框不再被整行拖動手勢包住。
- 完成操作使用明確的勾選狀態，不會因同一個舊 UI callback 重送而反向切換。儲存失敗時，checkbox 還原並顯示錯誤。
- 「日記紀錄」可展開，查看當時文字、完成／重新開啟時間；紀錄會保存至下次啟動。
- 輸入區旁的復原箭頭撤回最後一次操作，僅單步；重啟後不保留撤回狀態。

午夜時，正在看今天的頁面會跟隨新一天；已翻到其他日期的頁面保留原位置。

## 資料相容

Mac 資料位於 `~/Library/Application Support/FlowTasks/tasks.json`，使用原子寫入。每件事項保存類型、安排日期、重複規則、目前狀態及文字／時間紀錄；重複事項用期別日期記錄完成狀態，不需預先建立無限筆任務。

舊版資料可直接讀取。**舊版沒有安排日期的事項歸入「待完成」**；已有日期的事項歸入「日記」。原有完成狀態與紀錄保留；沒有時間的舊完成項目標明「未記錄時間」，不補造日期。若資料解碼失敗，App 停止寫入，保留原檔。

## 驗證與隔離 QA

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test
```

測試涵蓋原生 checkbox 首擊與點擊範圍、實際 NSHostingView 日記視窗內命中、完成與重新開啟、寫入失敗還原、重送操作、未來安排、過期延續、無期限待辦轉安排、週／月期間、每日／週／月重複、跨年、閏月月底、不漂移的月底重複、停止系列、提前完成、舊版相容與損壞檔保護。

```sh
./scripts/run-mac.sh --qa
```

QA App 使用不同 bundle identifier，資料位於 `.build/qa/tasks.json`。它與正常 App 的日記完全分開。只打包 QA：`./scripts/run-mac.sh --qa-build-only`。`FLOWTASKS_DATA_FILE` 僅於 Debug 建置提供測試檔案覆寫。

## 範圍

本輪功能與介面以 Mac 為主。iPhone 頁面／Widget 仍是舊原型，尚未配套新的目標與重複事項介面。未提供 iCloud 同步、通知、重複截止日期設定或 Apple Calendar 整合。資料仍以整份 JSON 儲存，尚未完成大量資料效能優化。Mac 面板未實作滑鼠移近自動展開。
